# Premium Tic Tac Toe

A high-fidelity, modern Tic Tac Toe game with stunning animations, glassmorphism, and smooth transitions.

## ✨ Features
- **Modern UI**: Dark-themed, glassmorphic design with vibrant gradients.
- **Dynamic Animations**: 
  - Drawing animations for 'X' and 'O'.
  - Hover effects with glowing borders.
  - Winning line animation.
  - Smooth board-reset transitions.
- **Scoreboard**: Track wins for both players.
- **Responsive**: Fully responsive layout for mobile and desktop.

## 🚀 How to Run
1. Open `index.html` in any modern web browser.
2. Alternatively, run a local development server:
   ```bash
   npx serve .
   ```

## 🛠️ Developed With
- **HTML5**: Semantic structure.
- **CSS3**: Custom properties, Flexbox/Grid, and keyframe animations.
- **JavaScript**: ES6+ modules and SVG path animation logic.
- **Typography**: [Outfit](https://fonts.google.com/specimen/Outfit) from Google Fonts.
